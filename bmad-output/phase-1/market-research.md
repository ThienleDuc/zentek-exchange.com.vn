## 3. Phân tích SWOT – ZenTek Exchange

### Strengths (Điểm mạnh)

- 🟢 **Chuyên biệt cho điện tử** → UX tối ưu cho ngành, danh mục chuyên sâu
- 🟢 **Kiểm duyệt bài đăng trước khi hiển thị** → Tin cậy hơn rao vặt
- 🟢 **Rating sản phẩm + Seller phản hồi** → Minh bạch, xây dựng uy tín
- 🟢 **Hệ thống chat đa dạng** → Chat cộng đồng (group), chat 1-1 buyer↔seller, chat 1-1 user↔user — tính năng độc đáo, tăng engagement & retention
- 🟢 **Thủ tục đơn giản** → Thu hút seller nhỏ lẻ bị "đẩy ra" từ sàn lớn
- 🟢 **Quản lý đơn hàng có lịch sử** → Minh bạch hóa giao dịch

### Weaknesses (Điểm yếu)

- 🔴 **Mới, chưa có user base** → Cold start problem, khó thu hút ban đầu
- 🔴 **Không tích hợp thanh toán & vận chuyển thực** → Hạn chế trải nghiệm hoàn chỉnh
- 🔴 **Chỉ web, chưa có mobile app** → Mất phần lớn user mobile-first
- 🔴 **Đồ án sinh viên** → Resource & thời gian hạn chế, chưa thể chạy production
- 🔴 **Kiểm duyệt manual** → Có thể gây delay cho seller, không scale được

### Opportunities (Cơ hội)

- 🟡 **Thị trường đồ refurbished/cũ tăng trưởng** — Gen Z tiêu dùng thông minh
- 🟡 **Gap rõ ràng giữa rao vặt và sàn lớn** — "Chợ Tốt thì thiếu trust, Shopee thì quá phức tạp"
- 🟡 **Xu hướng vertical marketplace** toàn cầu (StockX, Swappa, Reverb)
- 🟡 **Community-driven commerce** đang hot (Reddit + marketplace, Discord servers)
- 🟡 **Seller nhỏ bị thanh lọc từ sàn lớn** → tìm nơi mới, đơn giản hơn
- 🟡 **Có thể phát triển thành startup** nếu validate thành công

### Threats (Thách thức)

- 🔵 Shopee/TikTok Shop chiếm 97% thị phần, có thể mở chuyên trang điện tử
- 🔵 Facebook Groups mua bán điện tử đã có user base lớn, quen thuộc
- 🔵 Người dùng VN quen dùng platform có sẵn, ngại chuyển sang platform mới
- 🔵 Vấn đề pháp lý nếu phát triển thương mại thực (giấy phép, thuế)

- **Muốn**: Xem rating seller, đọc review thật, hỏi ý kiến cộng đồng trước khi quyết định

**Persona 3: Tuấn – Admin quản trị hệ thống**

## 5. Positioning & Differentiators

### Positioning Statement

> **ZenTek Exchange** = Sự đơn giản của Chợ Tốt + Trust system của Shopee + Chat cộng đồng kiểu Forum
> — chuyên biệt dành riêng cho mặt hàng điện tử

### Core Differentiators

| #   | Điểm khác biệt                 | Giá trị mang lại                                                         | So với đối thủ                      |
| --- | ------------------------------ | ------------------------------------------------------------------------ | ----------------------------------- |
| 1   | **Chuyên biệt điện tử**        | UX tối ưu, danh mục chuyên sâu, filter phù hợp (tình trạng, thương hiệu) | Chợ Tốt/FB: đa ngành, không chuyên  |
| 2   | **Kiểm duyệt + Trust system**  | Giảm scam, tăng tin cậy, rating minh bạch                                | Chợ Tốt/FB: không có trust          |
| 3   | **Hệ thống chat đa dạng tích hợp** | Chat cộng đồng + chat 1-1 (buyer↔seller, user↔user) → engagement cao, tư vấn realtime, cảnh báo scam | Không sàn nào có hệ thống chat đa dạng tích hợp trực tiếp |
| 4   | **Đơn giản thủ tục bán**       | Thu hút seller nhỏ lẻ, bán nhanh, chi phí thấp                           | Shopee: thủ tục phức tạp, phí cao   |
| 5   | **Quản lý đơn hàng minh bạch** | Lịch sử giao dịch rõ ràng cho cả hai bên                                 | Chợ Tốt/FB: không quản lý đơn       |

## 6. Kết luận & Khuyến nghị

### Đánh giá khả thi

| Tiêu chí              | Đánh giá                                                       |
| --------------------- | -------------------------------------------------------------- |
| Market need           | ✅ Có gap rõ ràng giữa rao vặt và sàn lớn                      |
| Differentiation       | ✅ Chat cộng đồng là unique, trust system fill gap             |
| Technical feasibility | ✅ Khả thi với tech stack phổ biến (React, Node.js, Socket.IO) |
| Scope cho đồ án       | ✅ Vừa đủ để demo ấn tượng, không quá lớn                      |
| Risk level            | 🟡 Trung bình — chat real-time là thách thức kỹ thuật lớn nhất |

### Khuyến nghị cho MVP

1. ✅ **Tập trung vào trust system** (rating, review, kiểm duyệt) — đây là core differentiator, phải hoàn thiện nhất
2. ✅ **Hệ thống chat đa dạng là "wow feature"** — MVP bao gồm cả 3 loại: chat cộng đồng (group), chat 1-1 buyer↔seller, chat 1-1 user↔user (tổng 8 Must Have features)
3. ✅ **Seed data chất lượng cao** (hình ảnh thật, mô tả chi tiết) — quan trọng cho demo bảo vệ đồ án
4. ⚠️ **Không nên mở rộng ngành hàng** trong phạm vi đồ án — giữ focus điện tử
5. ⚠️ **Responsive mobile** ở mức chấp nhận được, ưu tiên desktop UX hoàn thiện
